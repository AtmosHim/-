# 🎓 网课脚本

> 仅供学习参考，请合理使用，尊重课程规则。

---

## 📖 简介

本项目是我在上学期间为了更高效地完成网课任务而收集的脚本合集。  
支持 **慕课**、**智慧树**、**超星学习通**、**wnssedu** ·**长江雨课堂** 等平台，  
旨在辅助自动播放视频、跳过提问或快速完成章节。

---

## 🚀 食用方法（使用指南）

### 1. OCS & wnssedu

这两个平台的脚本需要通过 **篡改猴（Tampermonkey）** 扩展来运行。

**操作步骤：**

1. 在 Chrome / Edge / Firefox 浏览器中安装 [Tampermonkey 扩展](https://www.tampermonkey.net/)。
2. 点击 Tampermonkey 图标 → “添加新脚本”。
3. 将仓库中对应的脚本内容（`ocs.user.js` 或 `wnssedu.user.js`）**完整复制**并粘贴到编辑器中。
4. 按 `Ctrl + S` 保存。
5. 进入对应的网课页面，脚本会自动生效。

---

### 2. 长江雨课堂（Rain Classroom）

该平台脚本无需安装扩展，直接通过浏览器开发者工具运行。

**操作步骤：**

1. 使用 **Chrome / Edge / Firefox** 打开长江雨课堂的课程页面。
2. 按下键盘上的 **F12** 键，打开“开发者工具”。
3. 切换到 **Console（控制台）** 选项卡。
4. 将仓库中 `rain_classroom.js` 的脚本内容**完整粘贴**到控制台输入框中。
5. 点开scut.yuketang.cn的cookie文件夹，点击sessionid
6. 将sessionid的内容复制到脚本相应的地方
7. 按下 **回车（Enter）** 键执行。
8. 根据控制台弹出的文字提示（如输入章节序号、是否跳过问答等）进行交互操作即可。
